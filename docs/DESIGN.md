# Frontend Design Reference

The workspace-level `DESIGN.md` is the canonical UI design system. Follow its color tokens, typography, spacing, responsive behavior, component states, and accessibility requirements.

Do not duplicate the complete design system here because duplicated copies can drift. If this repository is cloned separately, obtain the approved shared `DESIGN.md` from the workspace documentation source before making UI changes.

When a design token or component rule must change, update the canonical design document and explain the reason.
